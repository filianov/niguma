        └───────────────┘

**Главный принцип связности:** имена аккаунтов уже «зашиты» в код. Создавайте их
**ровно такими** — иначе ссылки на сайте будут вести в пустоту:

| Сервис | Имя, которое ждёт код | Почему именно так |
|---|---|---|
| Telegram-бот | **@yoga15min_bot** | Telegram запрещает имена, начинающиеся с цифры |
| Telegram-канал | **@yoga15min** | то же ограничение |
| Instagram | **@15minyoga** | — |
| Facebook | **facebook.com/15minyoga** | — |
| Почта | **hello@15minyoga.com** | — |

> Если какое-то имя окажется занято — скажите, я поменяю его во всех файлах разом
> (оно встречается в 3 местах: `landing/js/config.js`, `config/project.config.json`, `bot/`).

## 3. ШАГ 2 — Хостинг + домен *(20 минут)*

### 3.1 Развернуть лендинг на Vercel
1. Зайти на [vercel.com](https://vercel.com) → **Sign up with GitHub**.
2. **Add New… → Project** → выбрать репозиторий `niguma` → **Import**.
3. **Root Directory** → нажать **Edit** → выбрать папку **`landing`**. ← критично!
4. Framework Preset: **Other**. Build Command и Output — оставить пустыми (это статика).
5. **Deploy**. Через ~30 сек получите адрес вида `niguma.vercel.app` — проверьте, что сайт открылся.

### 3.2 Подключить домен
1. В проекте Vercel → **Settings → Domains** → **Add** → ввести `15minyoga.com`.
2. Добавить также `www.15minyoga.com` — Vercel сам предложит редирект на основной.
3. Vercel покажет, какие DNS-записи прописать. Вариант зависит от регистратора:

**Вариант A — оставить DNS у регистратора** (проще):
| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `76.76.21.21` |
| CNAME | `www` | `cname.vercel-dns.com` |

**Вариант B — передать домен в Cloudflare** (гибче, бесплатный CDN и защита):
прописать у регистратора nameservers Cloudflare, затем в Cloudflare добавить те же записи
(режим **DNS only**, серое облако — иначе конфликт с сертификатом Vercel).

4. Подождать распространение DNS (обычно 5–30 минут, максимум 24 часа).
5. Vercel автоматически выпустит SSL-сертификат. Проверить: **https://15minyoga.com** открывается с замком.

> ❓ **Нужно от вас:** у какого регистратора куплен домен (GoDaddy / Namecheap / REG.RU / другой)?
> Дам точную инструкцию с экранами именно для него.

## 4. ШАГ 3 — Почта на домене *(30 минут)*

Нужна для `hello@15minyoga.com` — она уже прописана на сайте и в боте.

1. Выбрать провайдера: **Zoho Mail** (есть бесплатный тариф на 1 домен) или
   **Google Workspace** (~6 €/мес) или почта регистратора.
2. Создать ящик `hello@15minyoga.com`.
3. Прописать в DNS выданные провайдером **MX**-записи.
4. **Обязательно** настроить три записи — без них письма от бота уйдут в спам:
   - **SPF** (TXT): разрешает вашему провайдеру слать письма от домена
   - **DKIM** (TXT): подпись писем
   - **DMARC** (TXT): политика, начать с `v=DMARC1; p=none; rua=mailto:hello@15minyoga.com`
5. Проверить настройку на [mail-tester.com](https://www.mail-tester.com) — цель 9–10/10.

## 5. ШАГ 4 — Telegram *(20 минут)*

1. **Бот:** написать [@BotFather](https://t.me/BotFather) → `/newbot` → имя **`yoga15min_bot`**
   → получить `BOT_TOKEN` (длинная строка — это пароль, никому не показывать).
2. Там же: `/setuserpic` — загрузить `brandbook/logo/png/app-icon-512.png`;
   `/setdescription` и `/setabouttext` — короткое описание проекта.
3. **Свой Telegram ID:** написать [@userinfobot](https://t.me/userinfobot) → он ответит числом → это `ADMIN_IDS`.
4. **Приватный канал участников:** создать канал → назначить бота администратором →
   узнать его ID (переслать любое сообщение канала в [@userinfobot](https://t.me/userinfobot)) → это `MEMBERS_CHANNEL_ID`.
5. **Публичный канал** (по желанию): `@yoga15min` — на него ведёт ссылка в подвале сайта.

## 7. ШАГ 6 — Платежи *(1–2 часа, см. [PAYMENTS.md](PAYMENTS.md))*

Минимум для старта — ручные реквизиты, их выдаёт бот:

| Параметр | Где взять | Куда вписать |
|---|---|---|
| `PAYPAL_ME` | paypal.me — создать ссылку | `bot/.env` + `project.config.json` |

или Stripe Payment Links. **Рекомендация из аудита платежей: Paddle (Merchant of Record)** —
он берёт НДС всех стран на себя, вам не нужно регистрировать OSS.

## 9. ШАГ 8 — Запустить бота *(30 минут)*

1. Ключ Claude: [console.anthropic.com](https://console.anthropic.com) → API Keys → создать → `ANTHROPIC_API_KEY`.
2. [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo** → `niguma`.
3. Settings: **Root Directory = `bot`**, **Start Command = `python main.py`**.
4. **Variables** — перенести все переменные из `bot/.env.example` с реальными значениями.
5. Deploy → в логах должно появиться `15minYoga bot polling…` и список cron-задач.
6. Проверить в Telegram: `/start` → квалификатор → `/pay` → приходят ли реквизиты.

## 10. ШАГ 9 — Юридические страницы *(критично для Германии)*

| Страница | Статус | Что нужно |
|---|---|---|
| Политика конфиденциальности | ✅ черновик есть | проверка юристом |
| **Impressum** | ❌ **нет** | обязателен по §5 DDG: имя, адрес, e-mail, форма деятельности, при наличии — УНН |
| Оферта / условия участия | ❌ нет | правила оплаты, возврата, доступа к записям |
| Право на отказ (Widerruf) | ❌ нет | у потребителей в ЕС 14 дней; для цифровых услуг нужно явное согласие на немедленный доступ |

> ⚠️ В Германии отсутствие Impressum — самая частая причина «Abmahnung» (платного
> предупреждения от конкурентов или юрфирм). Это первое, что стоит закрыть.
> Я подготовлю шаблоны — от вас нужны юридические данные (имя, адрес регистрации).

## 14. Порядок действий — что за чем

Зависимости важны: некоторые шаги нельзя поменять местами.

```
1. Push на GitHub          ──┐
2. Vercel + домен          ──┼──▶ сайт живой
3. Почта (MX/SPF/DKIM)     ──┘
                              │
4. Telegram (бот, каналы)  ───┼──▶ 8. Бот на Railway ──▶ приём заявок
5. Соцсети                 ───┤
6. Платежи (реквизиты)     ───┤
7. Zoom                    ───┘
                              │
9. Юр. страницы            ───┴──▶ 10. SEO/аналитика ──▶ ЗАПУСК
```

**Минимальный путь до «можно продавать»:** шаги 1 → 2 → 4 → 6 → 7 → 8.
Почту, SEO и аналитику можно докрутить в первую неделю; Impressum — до первой рекламы.
