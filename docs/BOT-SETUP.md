# 🤖 Настройка ботов 15minYoga — пошагово

Инструкция для владельца проекта. Ничего программировать не нужно: вы создаёте боты
в Telegram, копируете ключи и вставляете их в панели двух сервисов.

---

## 0. Сначала — почему ботов ДВА

| Бот | Роль | Где живёт | Режим связи |
|---|---|---|---|
| **@yoga15min_bot** | Главный: воронка, оплата, напоминания, геймификация | Railway | long-polling |
| **@yoga15min_chat_bot** | Чат-виджет на сайте: FAQ и передача оператору | Vercel | webhook |

**Почему нельзя одним.** Telegram разрешает боту работать **либо** через long-polling,
**либо** через webhook — но не одновременно. Главный бот постоянно «висит на линии»
(polling), а чату на сайте нужен webhook, чтобы ловить ваши ответы оператора.
Поэтому это два разных бота. Для посетителя разницы нет.

---

## 1. Какой Telegram-аккаунт нужен

**Обычный личный аккаунт** — тот, с которого вы готовы отвечать клиентам. Отдельный
«рабочий» аккаунт заводить не нужно.

Требования:
- Аккаунт должен быть **активен на телефоне** (боты создаются только из приложения).
- Желательно задать себе **@username** (Настройки → Имя пользователя) — упрощает передачу заявок.

**Кто именно?** В коде поддерживается **несколько администраторов через запятую**.
Рекомендую указать оба аккаунта:
- **Ольга** — она оператор и преподаватель, отвечает клиентам по сути;
- **Павел** — техническая подстраховка, видит сбои и платежи.

Тогда уведомления об оплатах и сложных вопросах приходят обоим — ничего не потеряется,
если один занят.

## 2. Создать главного бота *(5 минут)*

1. В Telegram найдите **@BotFather** → нажмите **Start**.
2. Отправьте команду: `/newbot`
3. BotFather спросит **имя (display name)** — это то, что видят люди в шапке чата.
   Введите: **`15minYoga`**
4. Затем спросит **username** — техническое имя, должно оканчиваться на `bot`.
   Введите: **`yoga15min_bot`**

   > ⚠️ Именно так, а не `15minyoga_bot`: **Telegram запрещает имена, начинающиеся с цифры.**
   > Это имя уже прописано в коде сайта — если оно окажется занято, сообщите мне,
   > я поменяю его во всех файлах разом.

5. BotFather пришлёт **токен** вида `8123456789:AAHdqTcvC...`
   **Это пароль от бота.** Не пересылайте его в чатах, не выкладывайте на GitHub.
   Сохраните — это `BOT_TOKEN`.

### Оформить бота (там же, у @BotFather)

| Команда | Что ввести |
|---|---|
| `/setuserpic` | загрузить `brandbook/logo/png/app-icon-512.png` |
| `/setdescription` | «15 минут йоги каждое утро для предпринимателей и руководителей. Практика в 07:00 по будням, записи, закрытое сообщество.» |
| `/setabouttext` | «15minYoga — ежедневная практика для ясных решений» |
| `/setcommands` | вставить блок ниже одним сообщением |

```
start - Начать
menu - Меню
pay - Оплата
practice - Отметить практику
seed - Дневник семян
coffee - Кофейная медитация
dedicate - Посвящение
garden - Мой сад
invite - Пригласить друга
help - Помощь
```

## 3. Создать бота для чата на сайте *(2 минуты)*

Тот же путь, но другие имена:

1. **@BotFather** → `/newbot`
2. Имя: **`15minYoga Support`**
3. Username: **`yoga15min_chat_bot`**
4. Сохраните второй токен — это `TELEGRAM_BOT_TOKEN` для Vercel.
5. Аватар — тот же: `/setuserpic` → `app-icon-512.png`

## 4. Узнать свой Telegram ID *(1 минута)*

1. Найдите в Telegram **@userinfobot** → **Start**
2. Он сразу ответит числом вида `123456789` — это ваш ID.
3. Повторите со **второго аккаунта** (Ольга/Павел), если админов двое.

Запишите оба: `ADMIN_IDS=123456789,987654321`

---

## 5. Создать приватный канал участников *(3 минуты)*

Туда бот будет пускать оплативших и выкладывать записи занятий.

1. Telegram → **Новый канал** → название **«15minYoga · Участники»** → тип **Частный**.
2. Настройки канала → **Администраторы** → **Добавить** → найдите **@yoga15min_bot**
   → включите права **Публикация сообщений** и **Приглашение подписчиков**.
3. Узнать ID канала: напишите в канал любое сообщение → перешлите его **@userinfobot**
   → он покажет ID вида `-1001234567890` (обязательно **со знаком минус**).

Это `MEMBERS_CHANNEL_ID`.

---

## 6. Получить ключ Claude *(3 минуты)*

Это «мозг» бота: он отвечает на вопросы клиентов своими словами.

1. [console.anthropic.com](https://console.anthropic.com) → зарегистрироваться.
2. **API Keys** → **Create Key** → скопировать ключ вида `sk-ant-api03-...`
3. Пополнить баланс — минимального депозита ($5) хватит надолго: бот использует
   дешёвую модель Haiku для обычных вопросов.

Это `ANTHROPIC_API_KEY`.

---

## 7. Постоянная комната Zoom *(5 минут)*

1. Zoom → **Meetings** → **Personal Room** (или создать повторяющуюся встречу).
2. Включить **автоматическую запись в облако** — записи нужны участникам.
3. Скопировать ссылку для будней → `STREAM_LINK`
4. Для субботней глубокой практики можно завести вторую → `STREAM_LINK_WEEKLY`
   (либо указать ту же ссылку).

## 8. Ключи в **Vercel** — только для сайта

**Vercel → проект `15minyoga` → Settings → Environment Variables** → область **Production**.

Здесь живёт форма подписки и чат на сайте. Бота тут нет.

| Переменная | Значение | Для чего |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен **чат-бота** (@yoga15min_chat_bot) | уведомления с сайта |
| `TELEGRAM_ADMIN_ID` | ваш ID из шага 4 | куда слать заявки |
| `TELEGRAM_WEBHOOK_SECRET` | придумайте любую строку, напр. `y15m_hook_2026` | защита вебхука |
| `RESEND_API_KEY` | ключ с [resend.com](https://resend.com) | дубль заявок на почту |
| `LEAD_EMAIL_TO` | `15minyoga.com@gmail.com` | адрес получателя |
| `ANTHROPIC_API_KEY` | тот же ключ Claude | живые ответы чата *(необязательно)* |

После добавления: **Deployments → ⋯ → Redeploy**.

## 9. Ключи в **Railway** — для главного бота

**Railway → New Project → Deploy from GitHub repo → `niguma`**
Settings: **Root Directory = `bot`**, **Start Command = `python main.py`**

Затем **Variables** — вставьте всё разом (Railway умеет принимать блоком):

```
BOT_TOKEN=<токен главного бота из шага 2>
ADMIN_IDS=<ваш ID>,<второй ID>
MEMBERS_CHANNEL_ID=<-100... из шага 5>

ANTHROPIC_API_KEY=<ключ из шага 6>
CLAUDE_MODEL_FAST=claude-haiku-4-5
CLAUDE_MODEL_SMART=claude-sonnet-4-6

STREAM_LINK=<ссылка Zoom, будни>
STREAM_LINK_WEEKLY=<ссылка Zoom, суббота>

EUR_IBAN=<IBAN счёта>
EUR_BENEFICIARY=<получатель>
EUR_BIC=<BIC>
EUR_BANK=<название банка>

LIQPAY_LINK=<ссылка LiqPay>
CRYPTO_NETWORK=USDT-TRC20
CRYPTO_WALLET=<адрес кошелька>
PAYPAL_ME=<ссылка PayPal.me>

EMAIL_FROM=15minyoga.com@gmail.com
TIMEZONE=Europe/Vienna
DEFAULT_LOCALE=ru
AI_ESCALATE_THRESHOLD=0.55
DATABASE_PATH=niguma.db
```

Незаполненные платёжные строки можно оставить с `REPLACE_ME` — бот тогда честно
скажет клиенту «этот способ настраивается» и предложит другой, вместо того чтобы
выдать неверные реквизиты.

## 10. Проверка, что всё живо

**Главный бот:**
1. Откройте `t.me/yoga15min_bot` → **Start**
2. Должно прийти приветствие и меню → пройдите квалификатор
3. Команда `/pay` → должны прийти реальные реквизиты (не `REPLACE_ME`)
4. Задайте «сложный» вопрос (например, про травму спины) → вам в личку должно
   прилететь уведомление об эскалации
5. Команда `/stats` → покажет статистику (работает только для ADMIN_IDS)

**Логи Railway:** должно быть `15minYoga bot polling…` и список задач планировщика.

**Форма на сайте:** отправьте свой адрес → уведомление приходит в Telegram и на почту.

## 11. Частые ошибки

| Симптом | Причина |
|---|---|
| Бот молчит на `/start` | Не задан `BOT_TOKEN` или контейнер на Railway упал — смотрите логи |
| Приходит «этот способ настраивается» | В реквизитах остался `REPLACE_ME` |
| `/stats` не отвечает | Ваш ID не попал в `ADMIN_IDS` (проверьте: только цифры, через запятую, без пробелов) |
| Бот не пишет в канал | Бот не админ канала, либо ID канала без минуса |
| Уведомления не приходят | В `ADMIN_IDS` чужой ID, либо вы не нажимали Start у бота |
| Чат на сайте не отвечает | В Vercel не заданы переменные, либо не сделан Redeploy |

---

## 12. Безопасность

- **Токены — это пароли.** Их место только в панелях Vercel/Railway, никогда в коде и не в чатах.
- Если токен утёк: @BotFather → `/revoke` → выпустить новый и заменить переменную.
- Файл `.env` в репозиторий не попадает — он в `.gitignore` (проверено).

## 13. Чат на сайте — подключение

Виджет уже стоит на сайте. Без настройки он работает **автономно**: отвечает на 14 тем
выверенными формулировками и предлагает Telegram. Чтобы вы могли отвечать людям лично
прямо из Telegram, нужно два шага.

### 13.1 Хранилище диалогов (Upstash Redis, бесплатно)

Нужно, чтобы ваш ответ вернулся посетителю в окно чата.

1. Vercel → проект `15minyoga` → вкладка **Storage** → **Create Database** → **Upstash for Redis**
2. Тариф Free → **Create** → **Connect to Project**
3. Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` — руками ничего вписывать не нужно

> Без этого шага чат остаётся односторонним: вопросы приходят вам в Telegram, а посетителю
> виджет предлагает продолжить разговор в Telegram-боте. Это рабочий режим, просто менее удобный.

### 13.2 Включить приём ваших ответов (webhook)

Выполните **один раз** — вставьте в адресную строку браузера, подставив свои значения:

```
https://api.telegram.org/bot<ТОКЕН_ЧАТ_БОТА>/setWebhook?url=https://15minyoga.com/api/telegram-webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
```

Ответ `{"ok":true,"result":true,...}` означает, что связь установлена.

Проверить состояние можно так:
```
https://api.telegram.org/bot<ТОКЕН_ЧАТ_БОТА>/getWebhookInfo
```

### 13.3 Как это выглядит в работе

1. Посетитель пишет в чат на сайте → бот отвечает сам.
2. Посетитель просит человека (или спрашивает про здоровье) → **бот замолкает**,
   а вам в Telegram приходит уведомление с текстом вопроса.
3. Вы отвечаете **реплаем** на это уведомление — обычным ответом в Telegram.
4. Посетитель видит ваш ответ в чате на сайте в течение нескольких секунд.
5. Дальше вы переписываетесь как в мессенджере; бот больше не вмешивается.

**Важно:** отвечать нужно именно **реплаем** на сообщение бота — так система понимает,
какому посетителю адресован ответ. Обычное сообщение в чат с ботом никуда не уйдёт.

### 13.4 О чём бот говорит сам

14 тем: цена, расписание, что входит, оплата, пробное занятие, записи, новичкам, метод,
почему 15 минут, языки, здоровье *(сразу зовёт человека)*, возврат, как начать, живой оператор.

Тексты лежат в `landing/js/chat-content.js` и `landing/api/_chat-content.js` — правятся
как обычный текст, на 4 языках. **Бот не выдумывает**: цены, время и реквизиты он берёт
только из этих выверенных формулировок. Медицинских советов не даёт никогда.

Если задать `ANTHROPIC_API_KEY` в Vercel, Claude переформулирует тот же факт живее —
но добавить новый факт он не может по устройству запроса.
