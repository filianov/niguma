# 🗺 Дорожная карта 15minYoga

Пошаговый план: что сделать перед запуском и в ближайшие **30 / 90 / 365 дней**, плюс
**ветви развития** (страницы, боты, инструменты). Чекбоксы можно отмечать прямо в файле.

Принцип (YC): сначала вручную → автоматизируем отработанное. Один поток с 10 платящими
участниками важнее «идеальной платформы». Запускаемся на этой неделе.

---

## 🚦 Неделя 0 — подготовка к запуску (must-have)

**Аккаунты и доступы**
- [ ] Зарегистрировать домен (напр. `15minyoga.com`), подключить к Vercel/Cloudflare.
- [ ] Создать бота в [@BotFather](https://t.me/BotFather), получить `BOT_TOKEN`, имя `@yoga15min_bot`.
- [ ] Ключ [Anthropic Claude](https://console.anthropic.com) → `ANTHROPIC_API_KEY`.
- [ ] Узнать свой Telegram id ([@userinfobot](https://t.me/userinfobot)) → `ADMIN_IDS`.
- [ ] Создать приватный Telegram-канал участников, добавить бота админом → `MEMBERS_CHANNEL_ID`.
- [ ] Аккаунты: Instagram `@15minyoga`, Facebook-страница, Telegram-канал.

**Платежи** (см. [PAYMENTS.md](PAYMENTS.md))
- [ ] PayPal Business + `PayPal.me`/ссылки подписок.
- [ ] Реквизиты евро-счёта (IBAN/BIC) → `bot/.env`.
- [ ] Monobank «банка» (jar) → `bot/.env`.
- [ ] (Опц.) Открыть Wise Business для USD/GBP.
- [ ] Решить по MoR (Paddle) — для снятия НДС; можно после первых продаж.

**Контент и медиа**
- [ ] Снять/выбрать фото и короткое видео для hero и соцсетей.
- [ ] Сделать `assets/og-cover.jpg` (1200×630) для превью ссылок.
- [ ] Записать 3–5 видео о философии Нигумы (для блока «дополнительные видео»).
- [ ] Назначить Zoom-комнату (постоянная ссылка) → `STREAM_LINK`.

**Деплой и проверка**
- [ ] Задеплоить лендинг (`vercel --prod`), проверить 4 языка и кнопки.
- [ ] Заполнить `bot/.env`, поднять бота на Railway/Fly, проверить `/start`, `/pay`, `/practice`.
- [ ] Проверить эскалацию (задать «сложный» вопрос → приходит ли пинг автору).
- [ ] Юрист/Steuerberater: оферта, политика конфиденциальности, НДС-модель.

## 📅 Первые 30 дней — «запустить и продать первый поток»

**Неделя 1 — запуск**
- [ ] Анонс в Instagram/Facebook/Telegram: ссылка на лендинг → бот.
- [ ] Открыть набор в **первый поток** (старт в понедельник).
- [ ] Лично провести через бота первых 10–20 лидов (do things that don't scale).
- [ ] Каждый день: 15-мин эфир 7:00–7:15, суббота — глубокая часовая практика.

**Неделя 2 — первые продажи**
- [ ] Цель: **5–10 платящих участников** в первом потоке.
- [ ] Включить бесплатное пробное занятие как первый шаг.
- [ ] Собрать первые отзывы (текст/видео) — добавить на лендинг в блок «отзывы».
- [ ] Каждый вечер 10 минут: читать `message_log`, дорабатывать ответы бота и FAQ.

**Неделя 3 — ритм и удержание**
- [ ] Проверить, что напоминания (T-60/T-10) и записи доходят, посещаемость растёт.
- [ ] Запустить геймификацию: объяснить «Сад семян», команды `/practice`, `/seed`, `/garden`.
- [ ] Настроить выдачу записей активным участникам (YouTube unlisted / Cloudflare Stream).

**Неделя 4 — первая оптимизация**
- [ ] Разобрать воронку: где отваливаются (источник→`/start`→квалификация→trial→оплата).
- [ ] A/B заголовка hero и оффера пробного занятия.
- [ ] Подготовить анонс **второго потока**, прогреть тёплых лидов (`/broadcast`).
- [ ] KPI 30 дней: ≥10 участников, ≥40% посещаемость будней, лендинг-конверсия в `/start` ≥15%.

## 📆 31–90 дней — «повторяемость и автоматизация»

**Продукт и контент**
- [ ] Библиотека записей с навигацией (по неделям/темам) для участников.
- [ ] Серия философских видео по расписанию (контент-дрип в канал).
- [ ] Добавить страницу **«О преподавателе»** и **«Метод Нигумы»** на лендинг.

**Автоматизация воронки**
- [ ] Допилить drip под реальные возражения (из `message_log`).
- [ ] Включить churn-save (N пропусков → персональное сообщение) и авто-оффер продления.
- [ ] Лид-скоринг: приоритизировать «горячих» в анонсах и ручном касании.
- [ ] Подключить ESP (Resend), настроить SPF/DKIM/DMARC, e-mail-зеркало анонсов.

**Платежи**
- [ ] Подключить **Paddle** (MoR) для авто-checkout — снять НДС-нагрузку.
- [ ] Включить подписки PayPal/Stripe-ссылки на лендинге (`PAY_LINK_*`).
- [ ] Перенести бота с SQLite на **Postgres** (Supabase) для CRM-админки.

**Аналитика и качество**
- [ ] Plausible на лендинге; еженедельный дашборд воронки.
- [ ] GitHub Actions heartbeat (внешний пульс бота).
- [ ] Бэкап БД по расписанию.
- [ ] KPI 90 дней: 3 проведённых потока, ≥30 активных участников, MRR ≥ €2 000, доля авто-ответов бота без эскалации ≥70%.

## 🗓 91–365 дней — «масштаб и автономия»

**Рост аудитории**
- [ ] Реферальная программа (deep-link `start=ref_*` + перки) как основной канал.
- [ ] Партнёрства с сообществами предпринимателей и практикующими по Роучу.
- [ ] Контент-машина: Reels/Shorts по локалям, репост лучших эфиров.
- [ ] Полноценные локализованные версии лендинга EN/DE/UK (вычитка носителями).

**Продукт**
- [ ] Тарифные апгрейды: индивидуальные сессии, ретриты, корпоративные группы (для команд предпринимателей).
- [ ] Закрытое сообщество (доска щедрости, взаимопомощь участников).
- [ ] Сертификации/ступени практики, привязанные к уровням «Сада семян».
- [ ] (Опц.) Мобильное PWA поверх лендинга для участников.

**Автономия**
- [ ] Перевести 90% рутины на агентов; автор — только эфиры, контент, эскалации.
- [ ] Документировать runbooks/доступы (bus-factor): любой ассистент подхватит за день.
- [ ] Нанять part-time ассистента/комьюнити-менеджера на пики, бот разгружает остальное.
- [ ] Годовой обзор: юнит-экономика, LTV/CAC, отток, ценообразование.
- [ ] KPI 365 дней: стабильные ежемесячные потоки, ≥150 активных участников, MRR ≥ €10 000, ≤1 ч/день ручной операционки.

## 🌿 Ветви развития (страницы, боты, инструменты)

### Страницы лендинга (добавлять по мере роста)
- **Главная** ✅ (готова) — оффер, для кого, что получите, формат, цены, CTA.
- **О преподавателе** — история, линия передачи Нигумы, доверие.
- **Метод / Философия** — что такое йога Нигумы, связь с системой Роуча.
- **Отзывы / Кейсы** — социальное доказательство (текст/видео).
- **Записи (для участников)** — закрытая зона с доступом по подписке.
- **Блог / Видео** — SEO и контент-дрип (философия, причина-следствие, щедрость).
- **FAQ** — синхронизирован с базой знаний бота.
- **Оферта / Конфиденциальность** ✅ (privacy готова) — юр. документы.

### Боты и агенты
- **Поддержка/воронка-агент** ✅ (готов) — Claude в Telegram.
- **Агент-онбординг** — отдельный сценарий первых 48 ч участника.
- **Агент-контент** — генерирует/планирует посты и философские заметки по локалям.
- **Агент-аналитик** — еженедельный авто-дайджест воронки автору.
- **Reels/Shorts-ассистент** — нарезка и субтитры эфиров (по мере роста).

### Инструменты и интеграции
- **CRM-админка** (Supabase) — браузерное управление базой.
- **ESP** (Resend) — транзакционные письма и анонсы.
- **Платёжный MoR** (Paddle) — авто-checkout без НДС-боли.
- **Аналитика** (Plausible) — приватная веб-аналитика.
- **Хранилище записей** (Cloudflare Stream) — доступ по подписке.
- **Планировщик** (APScheduler + GitHub Actions) — cron и внешний heartbeat.

---

## Как пользоваться этой картой
1. Сначала закрыть **Неделю 0** — без неё запуск невозможен.
2. Двигаться по 30→90→365, не перепрыгивая: каждый блок опирается на предыдущий.
3. Раз в неделю сверяться с KPI и `message_log` — продукт уточняется реальными словами людей.
4. Автоматизировать только то, что уже отработано вручную.
