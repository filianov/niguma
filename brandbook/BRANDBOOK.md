## 1. Идея знака — «Четверть» (The Quarter)

Знак — это **таймер-кольцо, в котором подсвечена ровно одна четверть**.

| Элемент | Значение |
|---|---|
| **Полное кольцо** | час, день, целостность, цикл практики |
| **Подсвеченная четверть** (12→3 часа) | ровно 15 минут из 60 — то, что вы инвестируете в себя |
| **Точка в центре** | точка покоя, внимание, сам практикующий |
| **Разрывы между дугами** | воздух, дыхание; глаз достраивает круг сам (гештальт-принцип замыкания) |

Главное сообщение бренда — «нужна всего четверть часа» — заложено **в саму геометрию знака**,
а не в подпись. Знак читается и как часы/таймер, и как медитативная мандала.

### Принципы, по которым построен знак
1. **Простота** — 3 графических элемента, ни одной лишней детали.
2. **Читаемость на 16 px** — фавикон имеет собственную, более плотную геометрию (см. §5).
3. **Воспроизводимость в один цвет** — есть монохромные версии; знак не теряет смысла.
4. **Масштабируемость** — чистый вектор, от фавикона до фасадной вывески.
5. **Уместность** — спокойная геометрия и природная палитра вместо «спортивной» динамики.
6. **Запоминаемость** — уникальная асимметрия (четверть) отличает знак от круглых логотипов.

## 2. Логотип: состав системы

### 2.1 Горизонтальный локап — **основной**
`logo-horizontal.svg` — знак + начертание. Используется по умолчанию: шапка сайта,
презентации, письма, шапки соцсетей.

### 2.2 Вертикальный (стопкой)
`logo-stacked.svg` — когда место узкое и высокое: сторис, печать на одежде, аватар с подписью.

### 2.3 Только начертание
`logo-wordmark.svg` — когда знак уже присутствует рядом (например, в макете со знаком-иконкой).

### 2.4 Только знак
`mark.svg` — иконка приложения, аватар, водяной знак, маркеры списков, пиктограммы.

### 2.5 С адресом сайта
`logo-with-domain.svg` — для рекламы и раздаточных материалов, где нужен призыв к действию.

### 2.6 Монохром и инверсия
Для каждого локапа есть версии:
- `-mono-dark` — один цвет (графит) для светлого фона, факс, гравировка, тиснение;
- `-mono-light` — один цвет (бумага) для тёмного фона и фото;
- `-on-dark` — цветная версия, адаптированная под тёмный фон (повышенный контраст).

## 3. Цветовая палитра

Палитра «Earthy Neutrals» — тёплая, природная, спокойная. Основа — нейтральные тона,
акцент — терракота, «якорь» — олива.

| Роль | Название | HEX | RGB | CMYK (прибл.) |
|---|---|---|---|---|
| Фон основной | **Paper** | `#FBF8F3` | 251 248 243 | 0 / 1 / 3 / 2 |
| Фон секций | **Cream** | `#F0E3D3` | 240 227 211 | 0 / 5 / 12 / 6 |
| Дополнительный | **Sand** | `#DDBEA9` | 221 190 169 | 0 / 14 / 24 / 13 |
| **Акцент графический** | **Terracotta** | `#C58C6E` | 197 140 110 | 0 / 29 / 44 / 23 |
| **Акцент текстовый** | **Terracotta Deep** | `#A96C4C` | 169 108 76 | 0 / 36 / 55 / 34 |
| Вторичный | **Sage** | `#B8B7A3` | 184 183 163 | 0 / 1 / 11 / 28 |
| **Основной бренда** | **Olive** | `#6B705C` | 107 112 92 | 4 / 0 / 18 / 56 |
| Тёмный фон | **Olive Deep** | `#565B49` | 86 91 73 | 5 / 0 / 20 / 64 |
| Текст | **Ink** | `#3B382F` | 59 56 47 | 0 / 5 / 20 / 77 |

**Почему две терракоты.** `Terracotta #C58C6E` — для крупной графики (дуга знака): она мягкая
и не спорит с фоном. Для **текста** она недостаточно контрастна, поэтому цифры «15» в начертании
и мелкие акценты набираются более глубоким `Terracotta Deep #A96C4C` — он проходит порог
контраста для крупного текста (≥3:1 на светлом фоне). Это осознанное системное решение, а не
разнобой.

**Пропорции в макете (правило 60-30-10):**
60% — Paper/Cream (воздух) · 30% — Ink/Olive (текст и структура) · 10% — Terracotta (акцент).
Терракота — это специя: ею подчёркивают одно главное действие на экране, а не красят блоки.

**Печать.** CMYK в таблице — расчётные, для офсета обязательно сделайте цветопробу.
Pantone подбирайте по физическому вееру: ориентиры — олива в районе PANTONE 5763 C,
терракота — 7515 C, но **сверяйте вживую**, экранное совпадение не гарантируется.

## 5. Правила построения и охранное поле

- **Охранное поле** — не менее **0.3 от высоты знака** с каждой стороны. В это поле не заходят
  ни текст, ни другие логотипы, ни край макета. Схема: `logo/construction.svg`.
- **Геометрия знака**: радиус кольца = 0.344 × размер, толщина штриха = 0.095 × размер,
  подсвеченная дуга = ровно 90°, разрывы 7°.
- **Минимальные размеры:**

| Версия | Экран | Печать |
|---|---|---|
| Горизонтальный локап | 120 px по ширине | 30 мм |
| Вертикальный локап | 80 px по ширине | 22 мм |
| Только знак | 24 px | 8 мм |
| Фавикон | 16 px (спец. геометрия) | — |

**Фавикон — отдельная отрисовка.** У `favicon.svg` намеренно более толстый штрих, крупнее точка
и шире разрывы: на 16 px мастер-знак «залипает» в пятно. Это правильный приём, а не расхождение.

## 6. Чего делать нельзя

| ❌ Нельзя | Почему |
|---|---|
| Растягивать/сжимать непропорционально | ломается геометрия четверти |
| Менять цвета на непалитровые | разрушается узнаваемость |
| Добавлять тени, обводки, градиенты, объём | стиль плоский и спокойный |
| Поворачивать знак | четверть должна начинаться с «12 часов» |
| Ставить цветной логотип на пёстрое фото | использовать `-mono-light` или подложку |
| Менять шрифт начертания | начертание — это фиксированный вектор |
| Переводить название | `15minYoga` — имя собственное |
| Ставить логотип на фон с контрастом < 3:1 | не читается |
| Менять местами цвета кольца и четверти | четверть всегда акцентная |

## 7. Применение

**Сайт.** Шапка — `logo-horizontal.svg` (высота 30 px). Подвал — `logo-horizontal-on-dark.svg`
(высота 34 px, тёмный оливковый фон). Фавикон — `favicon.svg` + PNG-фолбэки.

**Соцсети.** Аватар — `app-icon.svg` / `png/app-icon-512.png` (олива + светлый знак, читается
в круглой обрезке). Обложка ссылки — `png/og-cover.png` (1200×630). Для Instagram-аватара
подойдёт и светлая версия `app-icon-light.svg` — выбирайте по фону ленты.

**Реклама.** На светлых макетах — `logo-horizontal.svg`; на фото и тёмных — `-on-dark`
или `-mono-light`. Для перформанс-макетов с призывом — `logo-with-domain.svg`.
Растровые версии: `png/logo-horizontal@2x.png`, `@3x` (прозрачный фон).

**YouTube.** Баннер канала — `logo/social/banner-youtube-2560x1440.png` (рекомендованный YouTube
размер; минимум платформы 1024×576 закрывает `banner-youtube-1024x576.png`). Тёмный вариант —
`banner-youtube-dark-2560x1440.png`. Фотоверсия с рассветом и практикой — `banner-youtube-photo-2560x1440.png` (+ `…-1024x576.png`): логотип в левой половине безопасной зоны, фигура и солнце — справа, так что оба элемента видны даже в самой узкой мобильной обрезке. Логотип и домен размещены внутри безопасной зоны **1546×423**,
которая видна на всех устройствах; декоративные кольца лежат в полосе, видимой на десктопе, и
безвредно обрезаются на телефоне. Фото профиля канала — `png/app-icon-512.png`.

**Печать и мерч.** Только SVG (вектор). Для одноцветной печати, тиснения, гравировки и вышивки —
`-mono-dark` / `-mono-light`. На тканях тёмных цветов — `-mono-light`.

**Документы и письма.** Горизонтальный локап в шапке, высота 8–10 мм, охранное поле соблюдать.
